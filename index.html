📖 About Tower of Hanoi

🏛️ History

The Tower of Hanoi was invented in 1883 by French mathematician Édouard Lucas. He was inspired by a legend from an Indian temple in Kashi Vishwanath, where Brahmin priests were tasked with moving 64 golden disks between three diamond needles according to specific rules. According to the legend, when all 64 disks are moved, the world will end.

The puzzle became one of the most studied problems in computer science and mathematics, commonly used to teach recursion and algorithm design.

🧮 Formula

The minimum number of moves required to solve the Tower of Hanoi with n disks is:

T(n) = 2ⁿ − 1
  • 3 disks → 2³ − 1 = 7 moves
  • 4 disks → 2⁴ − 1 = 15 moves
  • 5 disks → 2⁵ − 1 = 31 moves
  • 9 disks → 2⁹ − 1 = 511 moves
  • 64 disks → 2⁶⁴ − 1 ≈ 1.8 × 10¹⁹ moves (~585 billion years at 1 move/sec!)

⚙️ Algorithm (Recursive)

The classic recursive solution follows these steps for n disks from source A to target C using auxiliary B:

  • Move top n−1 disks from A → B (using C as auxiliary)
  • Move the largest disk from A → C
  • Move n−1 disks from B → C (using A as auxiliary)
hanoi(n, src, dst, aux):
  if n == 1: move src → dst
  else:
    hanoi(n-1, src, aux, dst)
    move src → dst
    hanoi(n-1, aux, dst, src)

📝 Steps to Solve (3 Disks)

Here's the optimal 7-move solution for 3 disks (A → C):

  • Move 1: Disk 1 → A to C
  • Move 2: Disk 2 → A to B
  • Move 3: Disk 1 → C to B
  • Move 4: Disk 3 → A to C
  • Move 5: Disk 1 → B to A
  • Move 6: Disk 2 → B to C
  • Move 7: Disk 1 → A to C ✅

💡 Tips & Strategies

  • For an odd number of disks, the first move should go to the target peg
  • For an even number of disks, the first move should go to the auxiliary peg
  • The smallest disk moves every other turn, always in the same direction
  • Never move the same disk twice in a row (in the optimal solution)
  • Use the Hint button to see the next optimal move if you're stuck!
